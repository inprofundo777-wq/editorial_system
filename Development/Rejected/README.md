# Rejected

Rejected содержит предложения, которые были рассмотрены и сознательно отклонены.

Rejected не является архивом ошибок.

Каждое решение прошло анализ, но не было принято по одной или нескольким причинам:

- противоречие архитектуре;
- дублирование существующего решения;
- недостаточная практическая ценность;
- преждевременность;
- высокая стоимость внедрения.

Отклонённое решение может быть рассмотрено повторно только при появлении новых оснований.

Повторное рассмотрение оформляется новым Proposal.

История прежнего решения сохраняется.
