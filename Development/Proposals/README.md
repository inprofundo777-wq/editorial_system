# Proposals

Proposal — это рабочее предложение по развитию Editorial System.

Proposal может содержать:

- наблюдения;
- анализ;
- варианты решений;
- обсуждение;
- рекомендации.

Proposal не изменяет систему автоматически.

После завершения анализа создаётся отдельный документ Process Decisions.

После утверждения Proposal получает статус:

Superseded

и остаётся историческим документом развития проекта.
