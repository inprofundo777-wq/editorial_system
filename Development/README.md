# Development

Development содержит историю развития Editorial System.

Здесь не создаётся постоянная нормативная документация.

Development используется для обсуждения, принятия и фиксации изменений архитектуры проекта.

## Жизненный цикл

```text
Идея
   │
   ▼
Proposal
   │
   ▼
Review
   │
   ▼
Process Decisions
   │
   ▼
Внедрение
   │
   ▼
Постоянная документация

           ▲
           │
      Новый опыт
           │
           └──────────────► Новый Proposal

Все изменения проходят жизненный цикл:

Proposal
→ Review
→ Accepted / Rejected
→ внедрение в постоянную документацию.

## Структура

### Proposals

Рабочие предложения.

Здесь обсуждаются идеи, наблюдения и результаты анализа.

Proposal не изменяет систему автоматически.

---

### Accepted

Принятые решения.

После утверждения Proposal создаётся отдельный документ решений.

Именно Accepted становится основанием для изменения постоянной документации.

---

### Rejected

Отклонённые предложения.

Rejected не является архивом плохих идей.

Это предложения, которые были рассмотрены и сознательно отклонены.

При появлении новых оснований они могут быть рассмотрены повторно через новый Proposal.

---

### Experiments

Экспериментальные решения.

Используются для проверки новых подходов до их возможного принятия.

Эксперимент сам по себе не изменяет Editorial System.
