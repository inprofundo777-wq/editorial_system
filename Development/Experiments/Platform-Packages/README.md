# Platform Packages — bounded pilot

Чат остаётся редакционной мастерской. Эта папка хранит лёгкие пакеты передачи и актуальный результат platform Editor.

## Граница пакета

Coach выбирает и передаёт источники, период и необходимый контекст. Он не интерпретирует за platform Editor возможные входы, жанры, композиционные движения или функцию конкретной публикации.

Platform Package показывает не то, как Editor должен работать, а то, с чем он работает и какой результат получил.

## Как работать

- Editor открывает ссылку на пакет и работает в своём обычном режиме.
- Пакет не повторяет инструкции роли и не задаёт обязательное количество публикаций.
- Готовый пакет Editor записывает непосредственно в раздел `Результат Editor` того же документа.
- Telegram: один файл охватывает одну неделю вокруг новой статьи.
- Facebook: один файл хранит поле нового контента и архива на четыре недели, но один запуск Editor охватывает не больше одной указанной недели.
- Существенная Owner-коррекция может быть кратко сохранена под результатом; промежуточные версии остаются в GitHub history.

Это рабочий эксперимент, а не VIA, registry, lifecycle или изменение постоянных ролей.
