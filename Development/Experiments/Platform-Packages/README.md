# Platform Packages — bounded pilot

Чат остаётся редакционной мастерской. Эта папка хранит компактный актуальный пакет публикаций и только существенные редакторские наблюдения.

- Telegram: один файл на фактическую неделю.
- Facebook: один файл на четыре фактические недели.
- В пакете сохраняются карта периода, актуальные тексты и material evidence.
- Если текст не восстановлен или ещё не подготовлен, место остаётся незаполненным.
- Пакеты не являются VIA, registry, lifecycle или новым policy document.
- Исторические версии сохраняются GitHub history; промежуточные редакции в пакет не переносятся.
