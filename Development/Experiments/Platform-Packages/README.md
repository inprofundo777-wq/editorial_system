# Platform Packages — bounded pilot

Эта папка хранит лёгкие матрицы передачи задания и актуальный результат Editor.

## Как работать

- Editor открывает ссылку на пакет и работает в своём обычном режиме.
- Пакет не повторяет инструкции роли и не задаёт обязательное количество публикаций.
- Источники и краткий замысел периода дают направление, но не предписывают композицию каждого текста.
- Готовый пакет публикаций Editor записывает непосредственно в раздел `Результат Editor` того же документа.
- Telegram: один файл охватывает одну неделю.
- Facebook: один файл показывает рамку четырёх недель, но один запуск Editor охватывает не больше одной указанной недели.
- Следующая Facebook-неделя передаётся отдельным запуском в этом же документе.
- Существенная Owner-коррекция может быть кратко сохранена под результатом; промежуточные версии остаются в GitHub history.

Это рабочий эксперимент, а не VIA, registry, lifecycle или изменение постоянных ролей.
