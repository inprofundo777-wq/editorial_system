# Experiments

Experiments содержит экспериментальные решения, проходящие практическую проверку.

Эксперимент используется для ответа на вопрос:

"Работает ли данная идея на практике?"

Эксперимент может привести к одному из результатов:

- принятие решения;
- отклонение;
- продолжение исследования.

После завершения эксперимента результаты оформляются через Proposal и далее проходят обычный процесс Development.

Эксперимент сам по себе не изменяет постоянную документацию Editorial System.
