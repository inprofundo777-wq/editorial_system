# Accepted

Accepted содержит решения, официально принятые для развития Editorial System.

Документы этой папки являются рабочим основанием для изменения:

- документации;
- Workflow;
- ролей редакторов;
- шаблонов;
- архитектуры системы.

Accepted не содержит полного анализа.

История обсуждения сохраняется в соответствующем Proposal.

Каждый документ Accepted должен:

- ссылаться на Proposal;
- содержать только принятые решения;
- определять порядок внедрения;
- оставаться неизменным после утверждения.

Если позднее потребуется изменить принятое решение, создаётся новый Proposal.

История прежнего решения не переписывается.
