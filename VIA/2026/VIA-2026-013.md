# Правила использования

- Настоящий файл является единым источником состояния данного редакционного цикла.
- Редакторы работают с одной активной ссылкой на VIA.
- Параллельные VIA или отдельные итоговые контейнеры не создаются.
- Результаты редакторов переносятся в соответствующие разделы настоящего VIA.
- Актуальное состояние определяется по паспорту, разделу `Текущее состояние` и истории статусов.
- Неиспользуемый этап не удаляется, а отмечается как `Not Required`.
- Рекомендация Coach не является окончательным решением владельца проекта.
- Наблюдения о системе не изменяют Editorial System автоматически.
- При закрытии VIA поле `Маркер закрытия` изменяется с `OPEN` на `CLOSED`.

## 14.6. Явный маркер закрытия

До завершения цикла:

```text
VIA STATUS: OPEN
```

После формального закрытия:

```text
VIA STATUS: CLOSED
```

При закрытии необходимо также:

- изменить статус VIA в паспорте на `Closed`;
- изменить поле `Маркер закрытия` на `CLOSED`;
- указать дату закрытия;
- внести запись в историю статусов.
