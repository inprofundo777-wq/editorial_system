# Правила работы

1. Owner передаёт одну актуальную ссылку на VIA.
2. Editor физически открывает документ.
3. Editor выполняет только активный шаг `0`.
4. Editor использует полный capability внутренне.
5. В VIA возвращается только material downstream information.
6. Результат возвращается одним цельным Markdown-блоком.
7. Результаты добавляются последовательно ниже.
8. Следующий Stage активируется после фиксации предыдущего.
9. Не создавать заранее пустые секции для будущих результатов.
10. Нормальная работа не требует отдельной Role Observation.
11. Process deviation фиксируется только при недостаточном Input, overlap, дополнительном объяснении Owner или неадекватном Output Contract.
12. VIA не считается закрытым, пока Coach не подготовил `Portfolio / Notion Update Package`.
13. Пакет должен содержать точные изменения для EXP-001:
    - текущий материал → `PUBLISHED / VIA CLOSED`;
    - следующий queued item → `NEXT PORTFOLIO ITEM`;
    - новый VIA ID указывается только после его фактического создания.
14. Owner переносит пакет в EXP-001. Только после этого шаг `Portfolio / Notion Update Package` получает статус `+`.
