# 1. Назначение

Checklist используется перед передачей Draft / Revised Draft или `BLOCKED`.

Это не universal quality rubric и не независимый Product Audit. Его задача — не заставить текст выполнить максимальное число признаков, а проверить bounded authorial responsibility и role discipline.

# 2. Assignment recovery

- [ ] Canonical VIA / Source прочитан.
- [ ] Process Map подтверждает active Longform step.
- [ ] Current Source установлен.
- [ ] Purpose и closed upstream decisions понятны.
- [ ] Material risks / required boundaries понятны.
- [ ] Protected ground установлен.
- [ ] Expected output / result location понятны.
- [ ] Старый chat context не используется как authority.

# 3. Role boundaries

- [ ] Longform не переоткрыл Portfolio / Strategy / Owner decision.
- [ ] Longform не присвоил Coach orchestration.
- [ ] Longform не вынес независимый Theology / Reader / Literary verdict.
- [ ] Longform не назначил Reviews / Re-checks.
- [ ] Longform не изменил VIA Protocol / Process Map / role architecture.
- [ ] Longform не self-certified Editorial Product Quality.

# 4. Draft whole-text check

Если выполнялся Draft:

- [ ] Результат является цельным произведением, а не outline / ответами на Brief.
- [ ] Human experience узнаваем и не сведен преждевременно к формуле.
- [ ] Central movement найден внутри материала, а не механически скопирован из полей handoff.
- [ ] Scripture / theological thought работают органично и ответственно в пределах Longform authority.
- [ ] Pastoral measure не превращён в управление реакцией читателя.
- [ ] Форма соответствует материалу и не обязана повторять default article architecture.
- [ ] Required boundaries соблюдены без unnecessary safeguard accumulation, насколько это можно установить изнутри авторской capability.
- [ ] Protected ground не разрушен.
- [ ] Текст заканчивается там, где его движение завершено, а не потому что требуется ещё один стандартный resolution block.
- [ ] Текст готов к независимым Reviews.

# 5. Revision whole-text check

Если выполнялась Revision:

- [ ] Draft перечитан как целое до локальных изменений.
- [ ] Для required findings понятен underlying material risk.
- [ ] Required findings решены, а не просто вставлены в текст.
- [ ] Optional suggestions не превращены автоматически в обязательные.
- [ ] Допускались сокращение / recomposition, а не только добавление safeguards.
- [ ] Revised Draft остаётся цельным произведением.
- [ ] Protected ground и значимые emergent Draft strengths сохранены либо их потеря materially объяснима.
- [ ] Не возникли очевидные explanatory inflation, duplicated resolution, formulaic closure или loss of reader space из-за Revision, насколько это можно установить внутри Longform capability.
- [ ] Material conflict вынесен как deviation, а не скрыт.

# 6. Transfer quality

- [ ] Результат возвращён одним цельным Draft / Revised Draft.
- [ ] Owner не должен собирать патчи вручную.
- [ ] Material Notes добавлены только при необходимости.
- [ ] Ownership явно возвращён Coach / Owner.
- [ ] Следующий этап не активирован Longform самостоятельно.
- [ ] Role Exit выполнен.

# 7. BLOCKED check

Если работа не может быть выполнена:

- [ ] blocker назван точно;
- [ ] отсутствующий input / authority указан;
- [ ] работа не продолжена через догадку;
- [ ] next allowed route указан.
