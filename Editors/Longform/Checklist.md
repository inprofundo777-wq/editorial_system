# 1. Назначение

Checklist используется перед передачей Draft / Revised Draft или перед возвратом `BLOCKED`.

# 2. Assignment recovery

- [ ] Canonical VIA / Source физически прочитан.
- [ ] Process Map подтверждает активный Longform step.
- [ ] Current Source / актуальная версия текста установлена.
- [ ] Closed upstream decisions понятны.
- [ ] Required boundaries понятны.
- [ ] Protected ground установлен.
- [ ] Expected output и result location понятны.
- [ ] Старый chat context не используется как authority.

# 3. Role boundaries

- [ ] Longform не переоткрыл тему / Portfolio / Strategy decision.
- [ ] Longform не присвоил Coach orchestration.
- [ ] Longform не вынес независимый Theology / Reader / Literary verdict.
- [ ] Longform не назначил Reviews / Re-checks самостоятельно.
- [ ] Longform не изменил VIA Protocol / Process Map / role architecture.

# 4. Draft quality

Если выполнялся Draft:

- [ ] Текст является цельной статьёй, а не outline или набором заметок.
- [ ] Сохраняется Human Entry.
- [ ] Сохраняется центральная функция материала.
- [ ] Композиция работает как единое движение.
- [ ] Required boundaries соблюдены.
- [ ] Protected ground не разрушен.
- [ ] Текст готов к независимым Reviews.

# 5. Revision quality

Если выполнялась Revision:

- [ ] Все required findings рассмотрены.
- [ ] Optional suggestions не превращены автоматически в обязательные.
- [ ] Revised Draft остаётся цельным текстом.
- [ ] Protected ground сохранён.
- [ ] Не создан новый material risk из-за локальной коррекции, насколько это можно установить в пределах Longform capability.
- [ ] Если возник material conflict, он вынесен как deviation, а не скрыт.

# 6. Transfer quality

- [ ] Результат возвращён одним цельным Draft / Revised Draft.
- [ ] Owner не должен собирать разрозненные патчи вручную.
- [ ] Material Notes добавлены только при необходимости.
- [ ] Ownership явно возвращён Coach / Owner.
- [ ] Следующий этап не активирован Longform самостоятельно.
- [ ] Role Exit выполнен.

# 7. BLOCKED check

Если работа не может быть выполнена:

- [ ] blocker назван точно;
- [ ] отсутствующий input / authority указан;
- [ ] работа не продолжена через догадку;
- [ ] next allowed route указан.
