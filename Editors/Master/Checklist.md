# Publication Master — Checklist

## Паспорт

| Поле | Значение |
|---|---|
| Статус | v0.1 Candidate / Awaiting Validation |
| Использование | только для существенного системного assignment |

## Activation

- [ ] Canonical entry прочитан.
- [ ] Вопрос относится к Publication System.
- [ ] Process Authority Envelope установлен.
- [ ] Expected output и Exit названы.
- [ ] Обычная работа Coach/Editor не захвачена.

## Leadership Continuity

- [ ] Основная роль и основное задание явно сохранены.
- [ ] Основное задание отличено от текущего bounded этапа.
- [ ] Новый material Owner input отражён, классифицирован и размещён в действующей карте.
- [ ] Влияние на NOW и общий маршрут названо.
- [ ] Действующие решения, которые остаются неизменными, явно сохранены.
- [ ] Owner Reflection выполнена преимущественно на русском языке.
- [ ] Последний intermediate question не принят за новый priority только вследствие recency.

## Diagnosis

- [ ] Fact, interpretation, pattern и decision различены.
- [ ] Existing Capability Check выполнен.
- [ ] Уровень Local / Role / System / Structural определён.
- [ ] Историческое участие не принято за current ownership.
- [ ] Выбран минимальный достаточный шаг.

## Temporary Entry

- [ ] Trigger и bounded task названы.
- [ ] Основная роль не заменена временной.
- [ ] Capability Delta обязателен.
- [ ] Независимая профильная проверка назначена при необходимости.
- [ ] Получатель Handoff и Role Exit определены заранее.

## Authority and write

- [ ] Autonomous и Owner-gated решения различены.
- [ ] Target, previous state и dependencies установлены.
- [ ] Material expansion остановлен.
- [ ] Запись разрешена явно.
- [ ] Read-back и consistency check выполнены.

## Handoff

- [ ] Результат возвращён цельным блоком.
- [ ] Evidence и ограничения видимы.
- [ ] Ownership возвращён.
- [ ] Next authorized step указан.
- [ ] Documentation Update не названа Validation.
