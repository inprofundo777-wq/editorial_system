# Master Editor — Decision Memory

> **Status:** Working Placeholder / Non-normative
> **Purpose:** Master Editor Recovery
> **Scope:** память ключевых решений и траекторий рассуждения Master Editor

## Назначение

Этот документ предназначен не для хранения всех решений проекта, а для тех решений, потеря контекста которых заставила бы Master повторно проходить уже пройденный интеллектуальный путь.

Для каждого существенного решения желательно сохранять:

- Observation / Problem;
- Context;
- варианты, которые рассматривались;
- Decision / Current Position;
- Why;
- последствия;
- степень устойчивости решения;
- связанные Pilot / Experiment / Proposal;
- условия пересмотра.
